# Assets Folder

This folder contains app assets like icons and splash screens.

## Required Assets

When you run `npm install` and `npx expo start`, Expo will automatically generate placeholder assets if they don't exist.

### Files needed:
- `icon.png` - App icon (1024x1024px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024px)
- `splash.png` - Splash screen (1242x2436px)
- `favicon.png` - Web favicon (48x48px)

Expo will create these automatically on first run if missing.
